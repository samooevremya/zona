# Миграция сохранений

Ключ сохранения игрока: `zona2d-kordon-v2` (localStorage). QA-прогоны с `#qa` в адресе пишут в `zona2d-kordon-qa` и не трогают сохранение игрока.

## Версии
- `mapVersion`: kordon-0.6 (нет поля) → kordon-0.7 → kordon-rc1. `saveVersion` = 3 (объявлен в g3.js).
- `S.dyn.v` = 2: снимок динамических NPC (напарник, SOS, группа заказа, торговцы с изменённым инвентарём, спасённые сталкеры).

## Что делается при загрузке старого сохранения (remapToMap + dynRestore, g9.js)
1. Перед любыми изменениями копия исходного сохранения кладётся в `zona2d-kordon-v2-backup-<старая mapVersion>`. Старая игра молча не пропадает.
2. Заказ зачистки и активный SOS пересчитывают точки по id локации. Если событие восстановить нельзя, оно закрывается как «не восстановлено» без штрафа.
3. На карте RC1 игрок переносится к костру деревни (якорь village.safe); в бункере остаётся в бункере. На прежней карте — на ближайшую проходимую клетку.
4. Деньги, инвентарь, состояние оружия, задания и флаги не меняются. В журнал пишется объяснение, что произошло.
5. Сохранения 0.6: заказ без id получает id, недостающая часть группы досоздаётся. Напарник, нанятый в 0.6, не восстанавливается: 0.6 его не записывала.

## Откат
Скопировать значение `zona2d-kordon-v2-backup-kordon-0.7` в `zona2d-kordon-v2` и открыть сборку с прежней картой (index_k07.html).
