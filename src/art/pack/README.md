# Деревня новичков — графика B, v1

Передайте Клоду весь ZIP вместе с сообщением: «Подключи графику из этого пакета к текущей версии игры, сохрани уже внедряемый HUD B/2. Начни с CLAUDE_START_HERE.md. Нужна настоящая графика в игре, не скриншот в качестве фона».

Внутри 28 элементов, сгруппированных в 4 PNG-атласа. Исходники имеют запас выше ×2 для целевых размеров. Прозрачность у объектов и крыш настоящая; ручное удаление фона не нужно.

- assets/terrain.png — трава, грунт, сухая трава, асфальт.
- assets/materials.png — дерево, бетонный пол, кирпич, бетон стен.
- assets/props.png — три кроны, куст, пучок травы, забор, бочка, ящик, машина, автобус, основание костра, люк, брёвна, обломки, тайник, скамья.
- assets/roofs.png — четыре крыши.
- manifest.json / manifest.js — реальные координаты, размеры и имена элементов.
- village-renderer.js — загрузка, отрисовка спрайтов, повтор материалов и плавный переход края; не меняет игру сам.
- preview.html — галерея после распаковки. Переключение игрового размера/×2 и фона.
- CLAUDE_START_HERE.md — точки интеграции и проверки, в том числе привязка крыш к шести домам.

Это первая версия ассетов для внедрения. У текстур повтор обрабатывается кодом зеркалированием; идеальная бесшовность исходных картинок не заявляется. Слияние grass/dirt задаётся по границам карты, не отдельной картинкой. Анимация огня и освещение остаются из игры. Персонажи и бункерная мебель не входят. Проверка на вашей новой сборке выполняется после интеграции Клодом.
