# Сборка игры

Исходники активной локации находятся в `winter/`. Команда `python3 src/build.py big` из корня записывает автономную игру в `index.html` и `src/index_big.html`.

Проверка в Chromium — `python3 src/qa/winter/check.py`. Для своего браузера укажите путь через переменную окружения `CHROMIUM_PATH`. Прежние модули остались в исходниках для переноса механик.
