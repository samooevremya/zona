# Правила для всех, кто правит игру (люди и нейросети)

0. **Перед визуальной правкой** прочитай [VISUAL_GUIDE.md](VISUAL_GUIDE.md) и сверься с референсом `src/qa/reference/reference.png`.
1. **Исходники лежат в `src/`.** Сборка: `cd src && python3 build.py big`, потом `cp src/index_big.html index.html`. Сайт берёт корневой `index.html`.
2. **Каждая правка идёт отдельной веткой и PR в `main`.** В описании PR пишите, что изменилось для игрока.
3. **Перед слиянием дописывайте запись в начало [CHANGELOG.md](CHANGELOG.md).** В записи должно быть:
   - дата и номер PR;
   - что изменилось для игрока;
   - какие файлы и функции затронуты;
   - каким ключом в адресе это выключается, если такой ключ есть.
   Так следующий участник видит, что уже сделано.
4. **Перед слиянием прогоняйте автотесты** из `src/qa/big/`: `run.py index_big.html`, `rc1run.py`, `runb.py`, `g7run.py`, `bigrun.py`, `touch_perf.py`. Все должны быть зелёными.
5. **Не меняйте без согласования с владельцем:**
   - цены и характеристики оружия;
   - формат сохранений;
   - 7 действий героя;
   - смену оружия по кругу.
   Кнопки должны оставаться не меньше 44 px.
6. **Снимки «до» и «после»** кладите в `src/qa/<тема>/`.
