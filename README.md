# Сотый километр

Зимняя игра с видом сверху. Герой начинает в Берёзках. На север ведёт станция между двумя частями поселения. На пути можно попасть только через вокзал.

Откройте `index.html` в браузере. Сборка целиком работает без сети. На клавиатуре WASD или стрелки отвечают за движение, Shift за бег, E за взаимодействие, M за карту. На телефоне используйте стик и контекстную кнопку. Карта поддерживает колесо мыши и масштабирование двумя пальцами.

Для сборки выполните `python3 src/build.py big`. Активная версия берёт код и графику из `src/winter/` и отдельные записи из `src/audio/`. Сохранения зимней игры находятся в своём пространстве имён. Сквозные проверки находятся в `src/qa/winter/check.py`.
