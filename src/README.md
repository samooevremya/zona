# Зона: исходники

Здесь всё, чтобы продолжить игру самому или с любым помощником.

- `../index.html` — готовая игра одним файлом. Именно его показывает GitHub Pages: https://samooevremya.github.io/zona/
- `src/` — исходный код, графика, сборка и тесты.
- `../gpt_originals/` — исходные картинки от GPT: блоки 1–4 (земля, растения, дома, предметы) и архив блоков 5–7 (персонажи, мутанты, оружие, HUD).

## Как собрать игру

Нужен Python 3.

```
cd src
python3 build.py big     # большой Кордон → index_big.html (это и есть ../index.html)
python3 build.py rc1     # прежняя карта → index.html
```

После сборки скопируй `src/index_big.html` в корень как `index.html`, закоммить и запушь. Через минуту-две сайт обновится.

## Как пересобрать графику из картинок GPT

Нужны Python-пакеты: `pillow numpy scipy`.

```
# блоки 1–4 → art/c1/c1.inline.js
python3 tools/c1_build.py ../gpt_originals
# блоки 5–7 (сначала распаковать архив) → art/g8/g8.inline.js
unzip ../gpt_originals/blocks5-7_characters_hud.zip -d /tmp/g8raw
python3 tools/g8_build.py /tmp/g8raw
```

Потом снова `python3 build.py big`.

## Что где лежит

- `g1.js` — константы, карта, генерация мира; `gbig.js` — большой Кордон (240×220, выходы, новые места).
- `g2.js` — сущности, ИИ, бой; `g3.js` — предметы, торговля, квесты; `gquest.js`, `gloc.js` — задания и места.
- `g4.js` — отрисовка: камера (`ZNEAR`), земля кусками (`GCH`, `GS`), кроны, крыши, тени.
- `g5.js` — запуск, управление, HUD, меню, авто-качество; `g6.js`, `g7.js`, `g9.js` — эффекты, звук, сохранения.
- `gg3.js`, `gg7.js` — растровые персонажи (кадры G3/G8, риг G7), оружие в руках, стиль HUD.
- `g8art.js` — растровая земля, деревья, дома, цветокоррекция под референс.
- `head.html`, `body.html`, `ui/` — разметка и стили интерфейса.
- `art/` — упакованная графика (c1 — мир, g7/g8 — персонажи и HUD).
- `qa/` — автотесты (Playwright + Chrome): `qa/big/run.py`, `rc1run.py`, `runb.py`, `g7run.py`, `bigrun.py`, `touch_perf.py`.
- `*.md` — отчёты и заметки по прошлым этапам.

## Полезные ключи в адресе (после #)

`#g8-off` — старые персонажи и HUD · `#c1-off` — старая земля · `#gs1` — земля в обычном разрешении (быстрее) · `#z=1.6` — масштаб камеры · `#shadow-off` — без теней · `#rig-on` — старый риг персонажей.
