# Визуальная база большого Кордона

Кадры игрового холста из сборки b160fa7. Окно 844 × 390 CSS-пикселей, стандартный масштаб, новая игра, параметр qa-seed=7. Интерфейс расположен поверх холста отдельным слоем и в эти изображения не входит. Координаты в клетках по 32 игровых пикселя.

Первое сравнение после правки земли проводить на выезде на шоссе. На исходном кадре левый край асфальта образует прямоугольную ступень, а тёмный след колеи повторяется поперёк грунтовки и двора. Цель первой правки — естественная обочина и колея, связанная с направлением проезда. Проверить также деревню и лес при том же масштабе.
