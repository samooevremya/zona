# Графика Свалки

Два оригинальных спрайта с прозрачностью, созданные встроенным ImageGen. Ширина полувагона в игре составляет 5,8 клетки. Отвалы растут до размеров целого двора. Исходные ориентиры региона описаны в [статье о Свалке](https://stalker.fandom.com/ru/wiki/Свалка). Остальные постройки и предметы используют атласы этой игры.

Photographic textures, gritty realistic muted colors, sharp legible relief at thumbnail size, no trees, no buildings, no perspective, no text. Complete isolated top view, alpha fringe, transparent background.
