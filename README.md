# Берёзки

Зимняя игра о выживании с видом сверху. Путь начинается в жилом корпусе Берёзок. Через станцию «Сотый километр» можно выйти на перрон и перейти по пешеходному мосту к озеру и рыбацкому посёлку. На юге стоит разрушенная военная база.

[Играть в браузере](https://samooevremya.github.io/zona/) · [Последние обновления](CHANGELOG.md)

Зимняя локация находится в `src/berezki/`. Общий движок, управление, графика и звук находятся в `src/`. GitHub Pages открывает корневой `index.html`.
