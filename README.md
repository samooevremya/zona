# Зона

Фанатская 2D-игра с видом сверху. Кордон и Малая Зона соединены западной грунтовой тропой. В Залесье есть костёр и личный ящик. К перегрузочному депо на Свалке можно дойти по шоссе от северного поста Кордона с поворотом после кладбища техники или по длинной лесной дороге от переезда Малой Зоны. Межрегиональные дороги развиваем по [схеме мира](docs/world-routes.jpg).
