# Кордон: предметы B2, пробная интеграция

19 иконок: 15 новых и 4 сохранённых из B1. Это дополнение к B1, не замена набора персонажей.

Новые: bread, sausage, vodka, medkit, antirad, grenade, ar_jacket, ar_bandit, flash, art_medusa, art_bengal, art_blood, tail, hoof, tentacle.
Из B1 без изменения: w_pm, bandage, cans, ar_zarya.
НЕ ГОТОВЫ: knife, w_obrez, w_aksu, a9, a12, a545. Лист оружия/патронов отклонён генератором; для этих шести ID оставить действующий рендер. Не подменять другим оружием.

## Подключение Клоду

1. Добавить items.inline.js в build.py до игрового JS. Он задаёт window.CORDON_ITEMS_B2 — словарь ID → data URL. Работает офлайн и через file://, fetch не нужен.
2. В b1Icon/itemIcon сначала искать ID в CORDON_ITEMS_B2, затем в старом B1, затем SVG fallback. Сохранить существующий переключатель графики, не ломать персонажей B1.
3. Нож идёт в gui.js itemCell отдельной веткой: пока не менять. Для остальных заменить только изображение. Количество, цена, износ, редкость, выбранность и рамка остаются слоями UI. Свойства ITEMS, цены и квесты не менять.
4. Убрать ограничение class tall только для ar_zarya: применить его также к ar_jacket/ar_bandit либо читать logicalSize из manifest.json. Все изображения вписывать с object-fit:contain. Не растягивать одежду в квадрат.
5. Проверить рюкзак, слоты экипировки, торговлю, корзину и обыск. В HUD гранаты/аптечки можно сохранить простые пиктограммы для читаемости; новая картинка предмета обязательна в инвентаре.
6. ПМ и «Заря» остаются прежними одобренными. ar_jacket/ar_bandit здесь иконки одежды, не новые тела персонажей. Артефакты и трофеи — адаптация для нашей 2D-игры, а не точная копия оригинальных ресурсов.

## Файлы и размеры

png/: отдельные PNG RGBA. Малые предметы 128×128 для 64×64 логических px; одежда 128×192 для 64×96. Разрешение 2× не означает удвоить размеры UI. ПМ сохранён из B1 в квадратном холсте, изображение внутри не растянуто.
atlas.png: 640×768, координаты прямоугольников в manifest.json. Не выводить атлас целиком вместо отдельных предметов.
items.inline.js: готовые data URL, не требует упаковки JSON загрузчиком.
preview.html: самостоятельный офлайн-просмотр иконок на размере 64 px.
source/: два крупных исходных листа, не подключать в игровой HTML.

## Приёмка

Сделать один кадр инвентаря со всеми 19 предметами, торговлю с несколькими новыми предметами в корзине и обыск. Это тестовые кадры: не выдавать игроку предметы в обычном сохранении ради демонстрации. Проверить 844×390 и 390×844 CSS, DPR 2/3; одежда целиком, прозрачный фон, надписи поверх картинки не исчезают, нет огромной бутылки относительно других ячеек.

Проверено при упаковке: 19 файлов, alpha, размеры 2×, прямоугольники внутри атласа, синтаксис inline JS. PNG просмотрены на нейтральном фоне. В игру пакет здесь не внедрён и на телефоне не проверен.
Генерация: встроенный генератор изображений; запрос — реалистичные рисованные иконки выживания, потёртые материалы, изолированные предметы с прозрачностью. Нарезка и уменьшение технические, цифры/рамки в изображения не добавлялись.
