# Кордон B — пробный статичный набор 1

Согласованные образы: одиночка в коричневой куртке, бандит, военный, слепой пёс, ПМ, бинт, консервы и облегчённая «Заря». Это пакет для проверки масштаба и читаемости в игре, ещё не полный набор анимаций.

## Файлы
- png/: 8 отдельных PNG с реальной прозрачностью, разрешение 2× относительно logicalSize.
- atlas.png: тот же набор в одном изображении 512×384, координаты в manifest.json/manifest.js.
- source/: исходный большой атлас и отдельные крупные вырезки для дальнейшей работы.
- renderer.js: небольшой Canvas-помощник на обычном JS, без JSX и сторонних библиотек.
- preview.html: автономная страница с изображениями на светлом/тёмном фоне, масштабами и вращением. Работает без сети; изображения встроены.

## Задача Клоду
1. Подключить на отдельном проверочном участке у костра. Не менять карту, коллизии, скорость и боевые характеристики. При отсутствии нового изображения оставить старую отрисовку.
2. У NPC loner/bandit/army выбрать соответствующий спрайт. У игрока loner допустим только как временный внешний вид коричневой куртки с ПМ. Внутриигрового персонажа в «Заре» здесь ещё нет: ar_zarya — иконка одежды.
3. Заменить иконки w_pm, bandage, cans, ar_zarya по действующим ID. Отдельной картинки обреза/автомата для инвентаря здесь нет.
4. Размер человека: холст 48×48 игровых px, файл 96×96; видимое тело уже холста. Пёс тоже 48×48, проверить масштаб рядом с человеком. Иконки 64×64 логических, «Заря» 64×96; файл вдвое больше. Не растягивать «Зарю» в квадрат.
5. Все персонажи смотрят вниз: исходный угол +PI/2 при оси Y вниз. Поворот Canvas = e.ang - PI/2. Точка pivot дана внутри холста в долях. Сверить с игровым центром/дулом; это стартовая настройка, не новая коллизия.
6. Сейчас ствол уже нарисован вместе с человеком: одиночка — ПМ, бандит — обрез, военный — компактный автомат. Не рисовать второй ствол поверх. При другом оружии, ноже, специальных позах сидения/смерти/приседания оставить прежний рендер. drawWorld возвращает false при несовпадении оружия — обработать fallback. В финальном наборе тело/оружие и анимации будут отдельными.
7. Один кадр допустимо вращать для этой проверки; это не восемь нарисованных направлений и не готовая анимация ходьбы. В движении не растягивать тело для имитации шага. Тень добавить отдельно с единым направлением света.
8. Сначала load manifest.js, затем renderer.js, загрузить atlas.png. Для одиночного HTML встроить изображение как data URL; JS ввести в существующую сборку build.py. Не добавлять fetch локального JSON при запуске через file://: использовать manifest.js.

Пример:
```js
const atlas = new Image();
atlas.src = 'art/b1/atlas.png'; // в single-file сборке заменить data URL
const gfx = createCordonSpritesB1(atlas);
// В мировом render, ctx уже переведён в координаты мира:
if (!gfx.drawWorld(ctx, 'loner', e.x, e.y, e.ang, e.wpn)) {
  drawOldHuman(e);
}
// Иконки: x/y — левый верхний угол ячейки, aspect ratio сохраняется:
gfx.drawIcon(ctx, 'ar_zarya', x, y, 64, 64);
```

## Приёмка
Кадр у костра на обычном игровом зуме: одиночка/бандит/военный/пёс. Затем тот же кадр с поворотом персонажей; предметы в инвентаре и торговле. Проверить светлый грунт, тёмный интерьер, отсутствие прямоугольного фона, двойного оружия и обрезанных краёв. На телефоне — 844×390 CSS и DPR 2/3, без увеличения физических размеров UI.

Проверено при упаковке: alpha-канал, 8 отдельных изображений, границы атласа, размеры 2×, синтаксис JS. В текущую игру пакет здесь не встраивался, на телефоне не проверен. После интеграции сначала правим масштаб/точки опоры, затем готовим направления и анимации.

Графика создана встроенным генератором по одобренным концептам. Задание генерации: реалистичные спрайты строго сверху, направление вниз, прозрачность; четыре персонажа и четыре предмета, лёгкая «Заря» без противогаза и тяжёлых плит. Механическая нарезка и уменьшение сохраняют исходный рисунок.
